# SalesBot: Agentic AI Sales Analytics & Decision Support System

SalesBot is an intelligent sales analytics platform that combines Business Intelligence, Data Warehouse, Recommendation Engine, and Agentic AI into a single web application.

## Live Demo

https://salesbot-analytics.streamlit.app

---

## Project Overview

SalesBot was developed as the final project of the Celerates Acceleration Mastery Program (CAMP) Batch 4 – Data Science & Generative AI.

The platform integrates:
- Data Warehouse Architecture
- Interactive Business Dashboard
- Recommendation Engine
- Agentic AI Assistant
- Conversational Analytics
- Automated Data Pipeline

## Features

### Dashboard Analytics
- Revenue Analysis
- Profit Analysis
- Product Performance
- Category Performance
- Province Performance
- Payment Method Analysis
- Sales Trend Analysis
- Forecast Analytics
- Business Alerts

### AI Sales Assistant
Natural language business analytics powered by Agentic AI.

### Recommendation Engine
- Product prioritization
- Market expansion opportunities
- Product quadrant analysis
- Revenue optimization suggestions

### Data Warehouse
Star Schema:
- fact_sales
- dim_date
- dim_product
- dim_location
- dim_payment
